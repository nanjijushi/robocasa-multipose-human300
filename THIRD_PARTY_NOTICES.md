# Third-party components

This repository references the following upstream projects as pinned Git
submodules:

- RoboCasa: https://github.com/robocasa/robocasa — MIT License
- OpenPI for RoboCasa: https://github.com/robocasa-benchmark/openpi — Apache-2.0
- robosuite: https://github.com/ARISE-Initiative/robosuite — MIT License

RoboCasa kitchen assets are downloaded separately from NVIDIA's official
Hugging Face dataset:

- https://huggingface.co/datasets/nvidia/PhysicalAI-Robotics-Manipulation-Objects-Kitchen-MJCF

The original model checkpoint is retrieved from:

- https://huggingface.co/robocasa/robocasa365_checkpoints

The checkpoint is not committed to this Git repository. Its upstream model card,
license notices, and any licenses inherited from model components apply.
